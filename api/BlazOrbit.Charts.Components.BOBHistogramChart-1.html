Class BOBHistogramChart<T>

Namespace
BlazOrbit.Charts.Components
Assembly
BlazOrbit.Charts.dll

Histogram - distribution of a single numeric variable. Auto-bins the raw Values using BinRule and renders each bin as a vertical bar. Includes a quantile readout (Median, P95) optionally shown via the ShowQuantileLines flag.
