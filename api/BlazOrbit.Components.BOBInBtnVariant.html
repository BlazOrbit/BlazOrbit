Enum BOBInBtnVariant

Namespace
BlazOrbit.Components
Assembly
BlazOrbit.dll

Visual modes for the internal _BOBInBtn primitive. Drives the data-bob-variant attribute so the scoped CSS can switch between the solid color-shift treatment and the transparent ghost treatment used by dismiss / close affordances across the library.

public enum BOBInBtnVariant

Fields

Default = 0

Filled-text button with color shift on hover/active. The historical default.

Ghost = 1

Transparent background with opacity dim until hover/focus — typical icon-only dismiss / close affordance.
